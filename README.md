# CSS Flag Project — Laos 🇱🇦

A recreation of the Laotian flag using HTML and CSS as part of my web development learning journey.

## What I Practiced

- CSS positioning with `position: relative`
- Moving elements using `top` and `left`
- Combining CSS selectors to target nested elements
- Using dimensions and calculations to position a circle
- Styling shapes with `border-radius`
- Understanding how positioned elements behave in normal document flow

## Tech Stack

- HTML5
- CSS3

## Key Learning

Practiced positioning a circular element within the flag using its dimensions and CSS offsets, while keeping the surrounding text in place.

A small exercise focused on understanding CSS positioning through hands-on practice.
